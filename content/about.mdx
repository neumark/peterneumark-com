Peter Neumark is a software engineer in Budapest. He writes here about the Web, AI and
software factories: the machines that ship applications, and what changes when a language
model writes most of the code.

This site is a [Grove](https://github.com/immediately-run/grove) wiki served by
[immediately.run](https://immediately.run): every page is one MDX file in a public
repository, rendered in the browser. Pull the platform pill to see the source, or to run
your own copy.
